Le code est la seule clé d'accès. Sans lui, personne ne peut entrer ni lire.

Qu'est-ce que Velum ?

Velum est une messagerie anonyme et éphémère. Il n'y a ni compte, ni pseudo permanent (un pseudo aléatoire est attribué à chaque session), ni base de données : le serveur ne conserve rien sur disque et ne journalise aucun message. Un salon existe uniquement en mémoire vive, pour la durée que vous choisissez.

Pourquoi le chiffrement est solide

🔐 AES-256-GCM

Standard utilisé par les gouvernements et les banques. Clé de 256 bits (2²⁵⁶ possibilités) : impossible à deviner par force brute. Le mode GCM assure aussi l'intégrité : tout message modifié est rejeté.

🧠 Zéro connaissance

La clé est générée dans votre navigateur avec un générateur cryptographique (Web Crypto). Elle n'est jamais envoyée au serveur. Il ne voit que du texte chiffré illisible.

🚪 Identifiant dérivé

Le serveur ne connaît qu'une empreinte SHA-256 du code, à sens unique : impossible de remonter à la clé.

🔥 Destruction totale

À l'expiration (ou après 5 min d'inactivité si activé), le salon disparaît de la mémoire du serveur et votre navigateur efface la clé et les messages.

Comment ça marche

  • Vous créez un salon : votre navigateur génère 32 octets aléatoires = le code secret.
  • Chaque message est chiffré avec un vecteur d'initialisation (IV) unique de 96 bits avant d'être envoyé.
  • Vous transmettez le code à vos correspondants par un autre canal (idéalement en personne ou via un canal sûr).
  • Le serveur relaie les données chiffrées et détruit le salon à l'heure dite.

⚠️ Limites honnêtes

  • Aucun système n'est « 100 % » sûr. Si quelqu'un obtient le code, il lit le salon : partagez-le prudemment.
  • Votre adresse IP est visible par l'hébergeur : utilisez Tor Browser ou un VPN pour un vrai anonymat réseau.
  • Un participant peut copier ou capturer les messages. Un appareil infecté compromet tout.
  • Le code JavaScript vient du serveur : hébergez Velum vous-même, en HTTPS, pour maîtriser cette confiance.
